# Limitations（可选）

**组织链：具体适用条件 → 对能力或使用的影响 → 有价值的改进方向。**

用户需要或目标会议要求时设置。默认一段，参考 100–200 英文词；内容少就短写，不凑字数。

- **写真正的适用条件：** 围绕真正影响使用的假设、数据覆盖、访问条件或成本，直接说明“需要什么，因此在什么情况下受限”。已经在方法和实验讲清的内容只作简短归纳。
- **改写时保持范围：** 改写已有 Limitations 时保持原有范围，不扩写、不新增限制条目；已有的不利说法删除，或改写为中性陈述的适用条件。
- **不自我贬低：** 不写无关自我贬低、泛泛“尚不完美”或逐项预演审稿意见。
- **改进方向有联系：** 只写与限制有实际联系的下一步，不承诺未经验证的效果。
- 决定主结论成立范围的条件仍必须在正文对应位置出现。

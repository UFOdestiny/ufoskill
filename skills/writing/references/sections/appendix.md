# Appendix

**组织链：按正文建立导航 → 理论或算法细节 → 完整复现设置 → 补充结果与分析材料。**

附录帮助读者追到需要的细节。按实际内容取舍，无相应内容就省略；长附录加简短目录。默认先放证明与算法，再放设置和结果。每节开头指出它补充正文哪一节、回答什么问题；标题直接说明内容，如 `Proof of Theorem ...`、`Implementation Details`、`Additional Results on ...`。

## 内容块

| 内容块 | 内部组织 |
|---|---|
| 证明与推导 | 对应正文性质 → 必要辅助结论 → 按依赖展开证明 → 回到原结论 |
| 算法与实现 | 对应主流程 → 省略的操作或分支 → 完整伪代码与实现细节 |
| 复现设置 | 数据及划分 → 模型与基线 → 训练／校准／推断 → 评价与统计 → 参数及资源 |
| 完整结果 | 对应正文表图 → 补充范围与设置 → 完整数值 → 新增趋势的简短解释 |
| 分析与材料 | 具体问题 → 变化的设置或案例选择 → 证据与解释；提示词、标注说明独立成块 |

**每节逻辑：正文对应问题 → 必要条件 → 细节或证据 → 解释。** 证明依赖清楚，补充实验沿用正文的研究问题，配置默认用表格呈现；不重新写一遍研究背景。

## 要求

- **双向可查：** 正文引用具体附录节、表、图或定理，附录注明对应的正文位置。符号、方法名与结果口径与正文一致；明确哪个是默认设置、哪个是变体。
- **复现信息完整：** 记录数据与标签在各阶段的用途、参数选择方式与实际值（正文以符号出现的参数逐一给出取值，符号与正文一致）、模型版本、运行预算及统计方法。评价指标必须给出形式化定义（公式），口径与实现代码一致（如并列分数的处理、覆盖率的取整）。提示词给输入占位符、示例、输出格式和解析规则；引用实际代码位置。
- **结果不堆叠：** 完整数值交给表图，文字只解释新增发现。只保留补足论证、支持复现或解释现象的材料，不把运行日志和无关失败尝试原样放入。
- 衔接词仅在有助于读者定位时使用。

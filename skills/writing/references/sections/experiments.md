# Experiments

**组织链：简明设置 → 总体比较 → 消融 → 机制验证 → 效率等进一步分析。**

先让读者理解比较，再用结果回答研究问题。方法论文按上述顺序组织；分析、理论或数据集论文没有方法比较时，按 general 中该类论文的主线组织结果。

## 小节与标题

- 每个小节都有明确意义，首句点明它回答的问题或检验的洞察，如 `This analysis confirms the key insight behind X: ...`。
- **小节标题用名词短语：** 不用问句或 RQ 式标题，标题中不出现无先行词的 `it`。实验类型直接作标题，如 `Main Results`、`Ablation Study of ...`、`Computational Efficiency`；验证动机或洞察的分析可用发现式名词短语，如 `Error Concentration at Coarse Granularity`。

## Experimental Setup（参考占实验文字 20%）

按 Datasets → Models → Baselines → Metrics 组织，使读者知道测量什么、比较谁、怎样比较。每个数据集、模型和基线名后紧跟各自引用；每类末尾用一句话指向附录对应小节，细节不在正文展开。

- **Datasets：** 以 `We evaluate X on [N] datasets` 开头给出总数，再按类型分组说明各组数量与名称；只说明用了哪些数据集、哪些用于训练、哪些用于测试，涉及分布迁移时说明哪些属于 ID、哪些属于 OOD。额外用于泛化的数据集明确写成 `[k] other datasets with unseen task types: ...`，不只写“两种任务类型”而让读者数不清数据集。划分、统计与预处理放附录。
- **Models：** 列出使用的模型，区分生成、评价、特征提取等角色；版本与推理配置放附录。训练用的 source 对象与迁移目标 target 对象分两组时，用连贯的句子写出二者关系，如 `We train X on labeled data from [k] source models ... . We then transfer ... , without any target label, to [m] held-out models ...`，不写成互不相关的两句。
- **Baselines：** 以 `We compare X with the following baselines.` 开头直接列举，不写 `Table~X compares ...`；按最接近路线、强比较方法与必要简单方法粗略分组；标明消融、使用额外信息的参考方法及引用结果。最后一句指向附录，如 `Detailed descriptions of these baselines are in Appendix~X.`
- **Metrics：** 先说成功标准，再说用了哪几类指标、各自含义及方向。交代会改变比较的标签、采样／调用预算、评价器与统计口径；置信度排序、概率校准、实际决策收益分别解释。正文不列指标公式，最后一句写 `Detailed definitions of these metrics are in Appendix~X.`；附录必须给出每个指标的形式化定义。

## 结果与分析（参考占实验文字 80%）

| 内容块 | 问题与推进关系 | 参考占比 |
|---|---|---:|
| 总体比较 | 核心目标是否改善 → 在哪些任务／规模成立 → 改善有什么意义 | 35% |
| 消融与机制验证 | 哪项设计带来收益 → 删除／替换后如何变化 → 哪项观察支持设计解释 | 25% |
| 进一步分析 | 主张还涉及什么能力 → 用效率、泛化、敏感性或案例揭示新增认识 | 20% |

**每个结果小节：要回答的问题与必要设置 → 关键发现 → 图表及代表性比较 → 对问题的回答。** 小节开头只说明本次改变了什么，不重复 Setup。结果段以发现为中心：读者先看到结论，再在相邻图表中定位证据。每节读完应得到答案，而不是一串数字。

- **总体比较讲模式：** 写总体趋势、关键差别和最有解释力的比较即可，完整指标由图表承载。报数数量与写法见[数字](../style/numbers.md)。
- **消融解释设计：** 比较完整方法与有意义的删除／替换，说明其他条件如何保持可比，并连回 Method 中的设计理由。性能下降说明组件有贡献，具体机制可结合中间量、控制实验或案例解释；按实际证据的力度写结论。
- **进一步分析带来新信息：** 效率给质量与成本的关系，泛化回答迁移到哪里，敏感性说明关键参数如何影响行为，案例展示平均值看不到的过程。按主张选择，不把每类分析都设为必做项。
- **图表与段落对应：** 每张图表有一个明确目的，正文解释其发现而非逐格朗读。
- **主次分明：** 主结果与理解贡献必需的验证留正文，完整分项、额外设置和次要案例放附录。与主线无关的负面讨论删除；改变主结论的结果在对应比较中直接说明，不另写一段自我辩护。

## 衔接

可选：`To test ...` 引出问题，`Table ... shows ...` 指向证据，`Compared with ...` 明确比较，`This suggests ...` 解释发现。

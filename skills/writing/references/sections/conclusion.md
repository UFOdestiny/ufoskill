# Conclusion

**组织链：完成了什么 → 核心认识或机制 → 证据确立的发现 → 这些发现意味着什么。**

默认一个自然段，参考 4–5 句、100–150 英文词；相邻功能可以合句。把全文提升到读者应记住的认识，不重新展开背景。

## 句子结构

| 位置 | 内部逻辑 | 默认衔接框架 | 参考占比 |
|---|---|---|---:|
| 首句 | 问题与核心贡献合写 | `We introduced ... to ... .` / `We have shown that ... .` | 25% |
| 第二句，可合并 | 提炼贡献背后的认识，解释关键改变 | `The key insight is that ... .` / `By ... , ... .` | 25% |
| 中间 1–2 句 | 概括最重要的实验发现或理论性质 | `Our results show that ... .`；必要时接 `Further analysis shows ... .` | 30% |
| 末句 | 落到新的认识、具体能力或实际收益 | `Together, these findings ... .` / `This enables ... .` | 20% |

## 要求

- **与引言呼应：** 回答最初提出的问题，收束认识、方法和证据，而不是重抄贡献列表。分析论文以发现收束，不补造方法句。
- **信息有取舍：** 不再次列出全部模型、数据集、指标和组件名。报数见[数字](../style/numbers.md)。
- **结束要有内容：** 不引入新实验、新假设或正文未讨论的能力，不用“推动领域发展”代替结论。无需例行添加弱点或未来工作；有明确延伸价值时，可用一句具体方向收尾。

## 衔接

`By` 连接机制与作用，`Our results show` 连接证据与发现，`Further analysis` 补充不同信息，`Together` 汇总多项发现。单一结果无需 `Together`；证据本身已说清意义时直接结束。

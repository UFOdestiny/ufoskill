# 表格

**组织链：一个比较问题 → 可比组与指标 → 完整结果 → 必要表注。** 正文如何引用表格见[交叉引用](../style/cross-references.md)。

- **按问题分组：** 主效果、消融与不同预算分清；方法名、模型和数据集层级明确，引用值与复现值注明来源。
- **突出实际结果：** 同一可比组内最优值加粗，次优值可加下划线，并列一致处理；本方法放对应组末尾，方法名可加粗，不把整行数字无条件加粗。
- **数字可读：** 表头给指标、单位与 ↑／↓，同列统一精度并对齐；缺失值用 `—` 并解释。有重复运行时说明次数与误差含义，显著性标记必须对应实际检验（见[数字](../style/numbers.md)）。
- **版式简洁：** 默认用 `booktabs`，只留表头、分组及必要分隔线，底色只用于必要处，不用密集网格。过宽时先精简表头、缩写方法名、拆表或跨栏；不用 `\resizebox` 或 `adjustbox`，字号最多缩到 `\small`，不用 `\footnotesize` 及更小字号。
- **表注与正文分工：** 表注精简，说明比较对象、条件、标记和缩写；结果表的表注说明指标、单位、关键条件及所示误差的含义。表头和分组标题已写明的信息不在表注重复，默认的汇总范围按[数字](../style/numbers.md)不写。正文提炼发现。
- **位置：** 表格靠近首次讨论，表注位置服从模板。靠前的表格在原位置就能读懂；结果表不早于其基线和指标的定义。
- **保留可编辑源：** 使用 LaTeX 表格，编译后核对越界、可读性、表注与数字一致性。

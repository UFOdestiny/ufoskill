**表格组织：一个比较问题 → 可比组与指标 → 完整结果 → 必要表注。**

1. **按问题分组。** 主效果、消融与不同预算分清；方法名、模型和数据集层级明确，引用值与复现值注明来源。
2. **突出实际结果。** 同一可比组内最优值加粗、次优值可加下划线，并列一致处理；本方法放对应组末尾，方法名可加粗，不把整行数字无条件加粗。
3. **数字可读。** 表头给指标、单位与 ↑／↓，同列统一精度并对齐；缺失值用 `—` 并解释。有重复运行时说明次数与误差含义，显著性标记对应实际检验。
4. **版式简洁。** 优先 `booktabs`，只留表头、分组及必要分隔线，少用底色，不用密集网格。过宽先精简表头、拆表或跨栏，避免缩成小字。
5. **表注与正文分工。** 表注说明比较对象、条件、标记和缩写，正文提炼发现。表格靠近首次讨论，表注位置服从模板。
6. **保留可编辑源。** 使用 LaTeX 表格，编译后核对越界、可读性、表注与数字一致性。

# Writing

写作规范集中于本 skill 的 `references/`。先读 [general](references/general.md)，再读本次涉及的章节；整篇写作按下列顺序组织。说明、讨论与修改理由用中文；论文正文沿用原稿语言，无原稿时默认英文，用户指定中文则写中文。

| 章节 | 读取内容 |
|---|---|
| Abstract | [摘要](references/sections/abstract.md) |
| Introduction | [引言](references/sections/introduction.md) |
| Problem Formulation | [问题定义](references/sections/problem-formulation.md) |
| Method | [方法](references/sections/method.md) |
| Experiments | [实验](references/sections/experiments.md) |
| Related Work | [相关工作](references/sections/related-work.md) |
| Conclusion | [结论](references/sections/conclusion.md) |
| Limitations，可选 | [局限](references/sections/limitations.md) |
| Ethical Considerations，可选 | [伦理考量](references/sections/ethical-considerations.md) |
| Appendix | [附录](references/sections/appendix.md) |

处理对应内容时，再读 [引用](references/presentation/citations.md)、[表格](references/presentation/tables.md)、[图示](references/presentation/figures.md)。研究来源与结构取舍见 [文献调查](references/writing-survey.md)，仅在追溯依据或更新规范时读取。

先从已有材料确定核心问题、洞察、机制和主结果，再调整章节及段落的职责，最后修改句子。直接完成用户要求的写作；局部修改保持局部，审阅请求只给诊断，审阅并修改则交付改稿。已有材料足够时无需另建计划文件或启动整篇审计。缺少会改变研究含义、结果取值或主张范围的信息时，询问用户；缺失结果可在工作稿中明确留位。

交付前检查：故事是否连贯，核心设计是否讲清，数字与引用是否对应，正文能否独立读懂。改动 LaTeX 后使用项目已有构建方式检查版面；无法构建时说明实际完成的检查。交付改稿和简短修改说明，不追加通用风险清单。
